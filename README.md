# Patrol Build Tracker V2

A Flask web app to track your Nissan Patrol build.

## Run locally

```bash
python -m pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

## Features

- Dashboard with overall progress
- Section progress cards
- Tasks with status colors and progress bars
- Parts tracker
- Costs tracker
- Updates / build diary
- Add, edit, and delete records
- SQLite database
- Mobile-friendly layout
